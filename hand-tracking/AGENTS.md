# Project preferences

## Code design

Use `~/.agents/skills/clean-project-design/SKILL.md` as the default for
implementation, architecture, and refactoring work. The preferences apply across
languages: cohesive components, reuse, bundled domain data, explicit dependencies,
appropriate patterns, and clear ownership.

## Diagrams

Use `~/.agents/skills/architecture-diagrams/SKILL.md` for architecture,
functionality, and data-flow diagrams. Keep the class/data/UI/file/external
distinctions consistent and adapt detail to the target audience. Existing
approved examples are `docs/architecture.md` and `docs/functionality_diagrams.md`;
trace current code when updating runtime facts.

## Saved NieR themes

When the user requests NieR Light/Dark, use
`~/.agents/skills/nier-ui-themes/SKILL.md` and its portable theme tokens.
Keep the user's selected theme and layout for other tasks.

These skills live in the personal skills folder and are shared across projects.
Explicit current user requirements take precedence over these defaults.
